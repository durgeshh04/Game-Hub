# Game Hub website

This is game searching website built to practice react.js skills

## Technology used:

- **React.js**
- **Vite**
- **Shadcn**
- **Tailwind CSS**

## Installation

Clone the project

```bash
  git clone https://github.com/durgeshh04/Game-Hub.git
```

Go to the project directory

```bash
  cd Game-Hub
```

Install dependencies

```bash
  npm install
```

Start the application

```bash
  npm run dev
```
